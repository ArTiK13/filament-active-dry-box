# Прошивка

Место для будущей прошивки контроллера. Кода пока нет; ESP32 рассматривается
как основа, ESP-IDF, Arduino или другая среда ещё не выбраны.

Требуемые режимы: осушение/хранение, регенерация, охлаждение.
Положения заслонок и состояния вентиляторов описаны в
[ТЗ](../docs/DESIGN_BRIEF.md). Пороги, переходы, запуск после сбоя и диагностика
потребуют отдельной спецификации перед реализацией.

После выбора платформы здесь появятся исходники, конфигурация сборки,
зависимости, тесты и команды прошивки. Сборочный вывод следует направлять
в `build/firmware/`; локальные пароли и настройки в Git не добавляются.
Подключения должны ссылаться на согласованную схему из
[electronics/](../electronics/README.md).
