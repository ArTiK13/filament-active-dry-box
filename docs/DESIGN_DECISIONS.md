# Решения и открытые вопросы

## Текущая механика v1

Утверждённые требования и размеры находятся в [DESIGN_BRIEF.md](DESIGN_BRIEF.md).
CAD содержит параллелограммный привод заслонок с передачей угла 1:1,
плечами по 18 мм, тягой 42 мм и открытием 82°. Механического фиксатора
конечных положений в этой версии нет.

## Удержание заслонок — обсуждение 15.10.2026

Пользователь предложил магниты у края, противоположного шарниру, чтобы
удерживать закрытую створку без постоянной нагрузки на серву.

Магнитный прижим полезен, но нужно решить две задачи:

- Большие заслонки при циркуляции подняты вверх; их вес стремится закрыть
  створки. Нужна фиксация открытого положения, а не только закрытого.
- Притяжение увеличивает момент начала открытия. Для плеча 132 мм суммарная
  сила 1 Н у края даёт около 0.132 Н·м, то есть 1.35 кгс·см, без трения,
  веса и прилипания уплотнителя. Это расчёт, а не замер конкретной сервы.

Обсуждены два варианта: магнитные фиксаторы обоих положений либо пружинный
механизм с переходом через мёртвую точку. Агент рекомендовал второй вариант
для дальнейшего изучения. **Пользователь попросил разработать обе версии отдельно, без выбора основной.**
Базовая CAD v1 сохраняется. Две альтернативы описаны в
[VALVE_VARIANTS.md](VALVE_VARIANTS.md) и реализованы в отдельном модуле
`cad/drybox_cad/retention.py`.

Для следующей итерации: жёсткие упоры для сжатия силикона, разгрузка редуктора
в обоих положениях, проверка усилия переключения на одной большой заслонке.
Размеры магнитов, параметры пружины и необходимость другой сервы определяются
после разработки и испытания механизма.

## Что остаётся определить

- Фактические размеры и уклон стенки ящика; посадки выбранных вентиляторов и серв.
- Конкретный PTC, сорбент, режим регенерации и термостойкий материал деталей.
- Схема электроники, датчики, питание, распиновка и программная платформа.
- Порог запуска и критерий окончания регенерации, охлаждение, обработка отказов.

Это задачи следующих итераций; прошивка и электронная схема пока отсутствуют.
